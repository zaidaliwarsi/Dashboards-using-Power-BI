#  Projects with Power BI and Excel

## 🧰 Tools & Technologies

- **Power BI Desktop** 
- **Python with Libraries like Pandas,Numpy, Matplotlib & Seaborn**  
- **Sample Dataset from Kaggle** ([Link](https://www.kaggle.com/))  
- **CSV File Format**

## 📁 Dataset Source

The data used in this project was obtained from a public dataset on **[Kaggle](https://www.kaggle.com/)**.
